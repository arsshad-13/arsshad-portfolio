# Portfolio V2.4 — visual polish update

## What's new
- Brand logos added to programming-language and technology badges using Simple Icons CDN SVGs.
- Technology logos are shown in the technical-skills cards and project technology stacks.
- Added a continuously moving technology rail below the hero introduction; it pauses on hover.
- Added subtle staggered skill-chip reveals, hover lift, violet glow, and project-card sheen effects.
- Reduced-motion preferences remain respected.

## Notes
- The technology logos are loaded from `https://cdn.simpleicons.org/` at runtime, so visitors need an internet connection to see those logo images. Text labels remain visible if a remote logo is unavailable.
- No live demo links have been added because none were supplied. Repository links remain the source links.
- Supplied project posters are presented as illustrative project previews, not verified application screenshots.

## Run locally
```powershell
npm install
npm run dev
```
